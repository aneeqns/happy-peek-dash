# Roadmap

- [x] Start screen with two choices: create a real account, or use a demo account
- [x] Real sign-up: Gmail address, username, password (Google sign-in also available)
- [x] Bank details collected on a "Finish setting up" step after the first sign-in
- [x] Demo path keeps the existing Customer / Creator demo workspaces (no money, no bank details)
- [x] Creator area locked behind a private code, checked on the server
- [x] Portfolio shows the customer's own holdings with live prices (add / remove)
- [x] Creator dashboard shows real platform figures (sign-ups, investors, most-held symbols)
- [x] Live market prices on Markets, Watchlist and Dashboard
- [x] Terms & Conditions page, linked from the bottom right of the start screen
- [x] Demo account: real market prices, user-chosen pretend money, buy/sell from the wallet
- [x] Publish to a permanent public link anyone can open
- [x] Run security scans and verify published protections
- [x] Fix verified security issues and run regression checks
- [x] Publish security fixes to the public site
